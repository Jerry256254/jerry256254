## KucLab

KucLab is my open-source software lab. I build personal AI agents, train language models from scratch and ship privacy-first web tools and browser games. Everything is public: [kuclab.org](https://kuclab.org) and [github.com/Jerry256254](https://github.com/Jerry256254).

## Flagship

### Gerin - [heygerin.com](https://heygerin.com)

A personal agent with its own computer. It gets an isolated workspace with a terminal and 2 GB of private disk, a browser that clicks through real pages, memory you can read and edit, scheduled tasks that run 24/7 with the tab closed, a public rail of mini-apps anyone can publish to, and an encrypted vault for logins. Closed beta: 30 days free, no automatic charge.

### LLM models - [Hugging Face / KucLab](https://huggingface.co/KucLab)

19 models and 30 datasets, all open weights:

- **Censer.1 - Censer.9** - safety text classifiers trained from scratch, Llama architecture, standard transformers export, 1.1M to 14.4M parameters, typo augmentation in later versions
- **kuclab-hertz-0.3 - 0.9f** - Czech and English text-generation LoRA adapters (STEM, programming, webdev) with self-distillation and GGUF export, on Qwen2.5-14B and Gemma-4-12B bases
- Training pipeline: [llm](https://github.com/Jerry256254/llm) - Docker-first fine-tuning on NVIDIA GPU with a web UI, GGUF export and Ollama import
